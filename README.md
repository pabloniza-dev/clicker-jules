# Cookie Clicker Web Application

A simple, interactive web application featuring a centered chocolate chip cookie and a live counter that tracks how many times the cookie has been clicked.

## Features

- **Centered Interactive Cookie**: Custom SVG chocolate chip cookie located in the middle of the screen.
- **Live Counter**: Dynamically tracks and displays the number of clicks.
- **Cookie Persistence**: Stores the total click count in browser cookies so your progress is saved across page reloads.
- **Interactive Animations**:
  - Hover and active click scale effects.
  - Floating `+1` pop-up animation at the cursor position upon each click.
- **Reset Button**: Allows users to reset the click count back to 0 at any time.
- **Clean File Structure**:
  - `index.html`: Contains HTML markup and embedded CSS styles.
  - `script.js`: Contains JavaScript application logic and cookie persistence helpers.

## Getting Started

1. Clone or download this repository.
2. Open `index.html` directly or serve via a local web server in any browser.
3. Click on the cookie and enjoy! Your click count will be saved automatically.
